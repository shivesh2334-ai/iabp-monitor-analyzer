# IABP knowledge maintenance

The corpus contains paraphrased, source-labelled passages from Krishna and Zacharowski (2009), the Nepean Hospital IABP Education Package, Webb et al. (2015), Getinge and ESC guidance. Review the sources against current device documentation and local policy before extending the corpus. The first eight chunks support the established learning flow.

Rules are maintained separately in rules.json. Each rule references a chunk and a page or section. Keep unverified device-specific conditions at TODO_VERIFY, increment the rules and corpus versions independently, and run the rule and API tests before rollout.
